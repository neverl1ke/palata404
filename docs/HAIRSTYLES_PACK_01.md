## Реєстрація на аватарі

Координати наведено на незмінному полотні тіла 941×1672, від верхнього лівого кута. `width` і `height` — розмір усього початкового PNG разом із прозорими полями. Для кожного ресурсу застосовано один рівномірний масштаб, без незалежного розтягування осей, зміни пікселів або пози тіла. Від'ємний y компенсує прозоре поле джерела, а не обрізає PNG.

## Зауваження після реальної примірки

Браузерна примірка v2 охоплює всі шість варіантів; попередні скриншоти v1 не підтверджують посадку нової відповідності файлів. Координати чотирьох замінених ресурсів перенесено разом із їхнім рівномірним масштабом та скориговано по y на 5 px під різницю верхньої точки базових голів. Для художнього перегляду залишаються лінія росту, щільність прилягання й перекриття вух; базові вуха не маскуються та PNG не домальовуються.

Для кешування кожний змінений PNG має актуальний hash-параметр URL; `index.html` запитує каталог `paper-doll-data.js?v=hairstyles-2`.

## Вибір і збереження

`appearance.hair` спільне для обох режимів. Нові й порожні вибори використовують `hair-none`. Старі невідомі рядки зберігаються як неактивні метадані й не стають шляхами до картинок. Вибір дозволяється лише з каталогу; `fittedToGender` забороняє помилкову підміну чоловічого ресурсу жіночим або навпаки. Невдале завантаження не змінює збережений вибір та показує чинну підказку відсутньої графіки.

## Перевірки та матеріали перегляду

Автоматичні перевірки охоплюють точні байти й альфа-канал шести PNG, чотири варіанти категорії, заміну попереднього волосся, статі, обидва режими, перезавантаження, старі збереження, «Без зачіски», незалежність екіпірування та відсутність змін характеристик. Браузерна примірка проходить на ширинах 1280, 390 і 320 px, разом із тунікою та жіночим допоміжним шаром.

У тестових артефактах зберігаються звичайні скриншоти гри, огляд по трьох зачісках для кожної статі та шість крупних планів. Огляди й крупні плани використовують точні DOM-копії фактично відрендереного ігрового компонента: збільшується весь зібраний персонаж, новий арт не генерується. Оцінювати остаточну лінію росту, вуха й контури слід за цими матеріалами; виявлені художні дефекти потрібно виправляти окремими погодженими замінами PNG за [стандартом](PAPER_DOLL_ASSET_PIPELINE.md).
