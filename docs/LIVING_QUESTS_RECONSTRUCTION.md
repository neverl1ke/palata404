Для К2 використано вцілілий оригінал ілюстрації допомоги Клари у робочому аркуші. Для повного ракурсу потрібен окремо погоджений шар Клари, рук і невеликої ділянки тканини, зареєстрований на фоні 406. Для Д3 показання підгину і шва подаються текстом. Окремих відновлених погоджених шарів для всіх варіантів підгину немає.
