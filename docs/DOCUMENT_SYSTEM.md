# Оформление документов «Палаты 404»

Текущий режим — только русский текст. По последней правке владельца переключатели языка удалены из игры и демонстрации; сохранённая ранее локаль игнорируется. Полная локализация игры отложена. `localization.js` сейчас содержит только русский реестр строк; имя `PalataI18n` сохранено для совместимости существующих потребителей. `setLocale` отклоняет другие языки.

## Компоненты

- `DocumentHeader`: `<document-header variant="left|center" department="documents.weapons" scale="normal">`. Эмблема, линии и настоящий текст — отдельные слои. Шапка слева на старом баннере сохраняет исходную бумагу, скрепку и анатомическую иллюстрацию.
- `DocumentPaper`: графический 9-slice с утверждённой фактурой `paper-source.jpg` и чистым центром `paper-center.svg`.
- `DocumentStamp`: прямоугольная служебная отметка либо точный утверждённый круглый оттиск `weapon-red-seal.svg` (`type="seal"`). Круглая печать не перерисована.
- `DocumentLayout`: контейнер бумаги, общей шапки и произвольного содержимого.
- `PalataDocuments.header({variant, department, documentType, scale, stamps})`: строковый API для существующего HTML/JS рендерера.

`document-demo.html` показывает оба стандарта, размеры 320/640/960 и произвольное название отдела. В текущей демонстрации один язык.

## Гардероб и архивный вкладыш

`wardrobe-archive.js` использует действующие предметы и расчёт оружия. Новых игровых механик или изменений сохранений нет. Убрана видимая кнопка счётчика модулей; обработчики установки модулей и сами установленные модули сохранены. Тест установки открывает существующий диалог через его API.

Картинки фонов редкости отделены от настоящих надписей и римских цифр. Позначки поворачиваются без перекоса и непропорционального масштабирования. Все карточки списка имеют один размер. Приклад не заходит на цветную полосу. Названия оружия на русском — только представление, исходные идентификаторы и данные инвентаря не меняются.

Нижний аркуш сохранён в согласованном размере: 230 px на широком экране, 200 px в коротком настольном окне, 205 px на самом маленьком телефоне. Данные пациента поступают из `playerName`, отделение — из `currentRoom`, карточка связана с `instanceId`, дата — текущая дата. Полное длинное имя доступно в `title`; значение в узком поле не перекрывает соседние строки. Заголовок и этап меняются с редкостью/прокачкой. Утверждённая подпись показывается через SVG-окно над неизменным оригиналом, без обрезания росчерка и без выхода за бумагу.

Шрифт `Marck Script` (OFL, `assets/fonts/MarckScript-OFL.txt`) используется только в рукописных полях и архивных заметках. Остальной текст — утверждённый машинописный шрифт.

## Материалы и повторное подключение

`assets/ui/wardrobe/battered-wood.webp` — состаренное дерево с глубокими бороздами от ногтей, остатками краски и тёмно-красными подтёками. Оно заполняет окно внутри прежнего металлического контура. `aged-leather.webp` — потёртая кожа под списком оружия. Графические ресурсы и источники перечислены в `assets/ui/documents/wardrobe-revision-provenance.json`.

Система уже используется в гардеробе и подробном после-боевом протоколе. Её можно подключить к медицинским картам, досье персонала, архивным записям и отчётам о рейдах через те же компоненты. Массовая переделка этих экранов не выполнялась.
