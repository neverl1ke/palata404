# Єдина система документів «Палати 404»

Система працює в наявному HTML/CSS/JavaScript без стороннього UI-фреймворку. Текст, папір, краї, емблема, кріплення та штампи — незалежні шари. Ігрові розрахунки, предмети, обробники кнопок і збереження персонажа не змінені.

## Компоненти

| Компонент | Призначення та параметри |
| --- | --- |
| `document-header` / `DocumentHeader` | `variant="left\|center"`, `department`, `document-type`, `scale`, необов’язковий `stamps` |
| `document-paper` / `DocumentPaper` | Паперова поверхня, окремі краї й центр. Товщина краю: `--paper-edge` |
| `document-stamp` / `DocumentStamp` | `type="service\|archive\|completed\|seal"`, `label`, `rotate`, `opacity`, `position="left\|right\|center"` |
| `document-layout` / `DocumentLayout` | Готовий паперовий контейнер; автоматично додає шапку за `variant`, `department`, `document-type`, `scale` |

`scale` приймає `normal`, `small`, `large` або число 0.85–1.2. Назву відділу можна передати ключем словника або звичайним текстом. Для автоматичного перекладу використовуйте ключ. Довільний текст відображається як текст, без HTML-виконання.

```html
<document-layout variant="center"
                 department="documents.staff"
                 document-type="documents.protocol">
  <section>Динамічний вміст справи</section>
  <document-stamp type="service" rotate="-7"></document-stamp>
</document-layout>
```

Шапка без зміни вже затвердженого паперу:

```html
<div class="existing-approved-paper">
  <document-header variant="left"
                   department="documents.wardrobe"></document-header>
</div>
```

JS-еквівалент для наявних шаблонних рядків:

```js
PalataDocuments.header({
  variant: 'center',
  department: 'documents.weapons',
  documentType: 'documents.service',
  scale: 'normal'
});
```

Підключення: `typewriter.css`, потім `document-system.css`; `localization.js` перед `document-system.js` і перед споживачами компонентів. Глобальні кольори, фактура, шрифт та відступи зібрані у `document-system.css`.

## Локалізація

У проєкті не було рушія локалізації. Створено спільний реєстр `PalataI18n` у `localization.js`, який зараз обслуговує документи. Це не масовий переклад решти гри.

```js
PalataI18n.setLocale('uk'); // ru / uk / en; без перезавантаження
PalataI18n.t('documents.ministry');
PalataI18n.t('documents.weaponFacts', {damage:45,total:55,critical:1.5});
```

Перемикач доступний у налаштуваннях, у верхньому службовому блоці гардероба та на демонстраційній сторінці. Нова незалежна перевага `palata404_locale` не змінює наявні збереження гри. За недоступного сховища перемикання працює до закриття сторінки.

Подія `palata:localechange` оновлює текст компонентів і `[data-i18n]`. Динамічні значення можна передавати через JSON у `data-i18n-params`. Перенесення назви установи контрольоване двома рядками; `ResizeObserver` та очікування завантаження шрифту виконують обмежене зменшення шрифту до 78% для довгих перекладів. Фон і координати декоративних елементів від мови не залежать.

**Уточнення власника про печатку має пріоритет:** кругла печатка завжди використовує незмінений затверджений `weapon-red-seal.svg`. Її історичний напис є частиною затвердженої графіки й не перемальовується для мов. Локалізуються доступний опис, усі нові текстові штампи, назви установи та відділу, службові позначки й підпис лікаря. Це свідомий виняток із початкової вимоги локалізувати всі написи печатки; нова печатка не створювалася.

## Художні ресурси

- `assets/ui/documents/paper-source.jpg` — точна копія наданого `28323.jpg`, без перекодування.
- `assets/ui/documents/paper-center.svg` — пропорційне відображення чистої центральної ділянки того самого незміненого зображення. Оригінал вбудований без редагування пікселів.
- Кути й краї: 9-slice із зрізом 90 px; їхня товщина задається незалежно від розміру документа. Фоновий центр використовує `cover`, а не непропорційне розтягування. М’яка маска стику поєднує центр із 9-slice. CSS-градієнт використано лише як маску прозорості, а не заміну фактури.
- `paperclip.png` — окремо підготовлений декоративний ресурс за референсом для стандартної HEADER-LEFT. У гардеробі він не замінює оригінальну скріпку.
- Емблема — незмінений `requested-header-emblem.webp`.
- Печатка, підпис, стара художня шапка, планшетка та її кріплення — попередні затверджені ресурси. Металеві деталі відображаються окремою SVG-відсічкою оригінального атласу, а не новою генерацією.

SHA-256, джерела й перевірка незмінності — `assets/ui/documents/provenance.json`.

## Уже застосовано

1. Верхня шапка гардероба: попередній папір з анатомічним малюнком і скріпкою збережено; змінено посадку живого тексту.
2. Планшетка зброї: збережені основа, кріплення, потертості, плями та затверджена печатка. Новий папір накладено на обидва аркуші. Основна шапка центрована й збільшена, нижній аркуш компактніший. Планшетка вміщується без прокручування; каталог предметів залишається окремим прокручуваним списком.
3. Детальний післябойовий протокол: центрована шапка й спільний паперовий контейнер. Короткий підсумок нагород залишено компактним; його кнопки й поведінка збережені.

Готове до наступного підключення: медичні картки, досьє пацієнтів і персоналу, архівні записи, звіти про рейди, сюжетні документи та інші картки спорядження. Їх не перероблено масово.

## Демонстрація й перевірки

Відкрийте `document-demo.html` через той самий локальний або ігровий вебсервер. Є два варіанти шапки, RU/UK/EN, ширини 320/640/960 px, стандартні та довільні назви відділів і приклад повного документа.

Результати та знімки — `review/document-system-20261106/README.md`. Перевірки вміщення планшетки виконуються окремо для трьох мов на шести розмірах екрана, включно з 320×568. Фізичні мобільні пристрої й Telegram WebView не перевірялися.
