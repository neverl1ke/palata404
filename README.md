# Палата 404

Невелика браузерна гра в жанрі рольової пригоди з боями, розвитком персонажа та дослідженням поверху психіатричної клініки.

## Запуск

Проєкт не потребує збірки чи встановлення залежностей. Відкрийте `index.html` у браузері або розмістіть усі файли репозиторію на статичному вебхостингу. Для Telegram Mini App потрібен доступний через HTTPS вебсайт, підключений у налаштуваннях бота.

## Керування та збереження

Гра працює у браузері. Нікнейм, характеристики, спорядження, інвентар і прогрес зберігаються в `localStorage` цього браузера. Очищення даних сайту або перехід на інший пристрій може видалити чи не перенести збереження.

Список «сусідів по блоку» та рейдова кімната наразі працюють локально в межах цієї сторінки. Серверної синхронізації між гравцями немає.

## Структура

- `index.html` — розмітка екранів, модальних вікон і арени бою.
- `style.css` — стилі та адаптація інтерфейсу для вузьких екранів.
- `script.js` — ігрова логіка, прогрес, бій і локальне збереження.
- PNG та JPG у корені — карти, фони й графіка персонажів.

Зовнішні шрифти завантажуються з Google Fonts; гра може відкритися без них, але вигляд тексту зміниться.
