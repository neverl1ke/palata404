# Male Avatar Core — грудне дихання та незавершений pass хватів

**Частковий результат. Хвати rifle і pistol НЕ виправлено.** Інструмент генерації двічі відхилив локальне редагування кистей із категорією `violence`. Нового малюнка долоні, пальців чи великого пальця не отримано. Відмови з request ID записані в image-generation-failures.json; повторів або обходу обмеження не було.

Виконано незалежну частину: трохи виразніше дихання грудної клітки, незмінні руки/props і цикл4000мс, окрема пропозиція переходів. Зелений тест не вважається художнім виправленням пальців.

## Як працює грудне дихання

У male-preview.json додано тільки chestDetail:

- центр[474,466], радіуси[190,150] у вихідних px;
- horizontal0.022, vertical0.014;
- підтримка w=max(0,1−dx²/rx²−dy²/ry²)²;
- додатковий зсув=(dx·horizontal·breath·w, dy·vertical·breath·w).

Ті самі phase/time/cycleMs. Рівномірна сітка24px відображає вихідну текстуру грудної клітки; нова текстура не створюється. Підкладка торса, зовнішній силует і його альфа-край малюються попереднім способом. Додаткова поверхня обмежена внутрішнім еліпсом непрозорої шкіри, не зачіпає шию, плечі чи живіт. На нульовій фазі використовується старий шлях без додаткової поверхні.

Жодний додатковий зсув не надходить у solver рук або prop. Профілі мікрорухів із7ba0863 збережені. У тесті ввімкнення/вимкнення нової поверхні весь frame, включно з матрицями зброї та контактами, однаковий.

Фактичні виміри: максимальне додаткове зміщення1.17846 вихідного px, мінімальне відношення площі трикутника0.961986,0 змінених вершин поза підтримкою;33 відліки за4000мс. На ширині аватара470px це приблизно0.59 CSSpx додаткової амплітуди, близько1.18 CSSpx повного розмаху. Це делікатне підсилення, не рух усієї фігури.

- Повноростові рендери всіх4 поз.
- Крупні плани rifle/right, rifle/left, pistol, wrists/elbows/shoulders, опори приклада.
- Статичні порівняння свідомо однакові: це **доказ незміненої постановки**, а не виправлених хватів.

- Реальний Chromium, desktop і viewport320/390/768px; фізичного телефона й інших рушіїв не перевірено.

## Перевірки

Нові3 тести: побайтова незмінність усіх PNG/ригів і функції setPose; піксельна локальність грудного руху та незмінність frame/контактів; позитивна топологія й числовий бюджет додаткового розширення. Чинний тест майже нерухомого pistol з бюджетом<0.4 CSSpx не послаблено.

Повний поточний Python/Chromium прогін: результат у test-logs/regression.log. JavaScript — актуальні журнали game-js.log і core-js.log. Фактичний підсумок: **49/49 Python/Chromium** (163.019с) і **115/115 JavaScript** (95 ігрових+20 Core). Нові тести —3; це не3 нові художні правки. Пакет перевіряється після розпакування через file://, CRC і хешами; дані у offline-package-check.json. Історичні галереї й їхні результати не підмінялись.

## Невиконане й наступний крок

Потрібен художній ресурс правильної кисті на кожному grip: пальці, великий палець, долоня, зап’ястя й окремі передні/задні перекриття. Поточні текстури цього не містять; просте обертання чи перестановка шарів не створить правильної анатомії. Для завершення потрібна локальна ручна ретуш художником або доступний інструмент, який може виконати ці конкретні правки. Стан не позначається production-ready.

Новий дихальний рух стосується видимої шкіри; готовий одяг не перемальовували й систему гардероба не змінювали. Для майбутніх сильно прилеглих торсових речей потрібно окремо погоджувати, чи вони успадковують локальне розширення тканини. Зараз Binding API збережений, інвентар і сейви не записуються.

Публікується тільки окремий оглядовий пакет за дозволом користувача. Злиття в main й публікація гри не виконуються.
