# Male Avatar Core 2.0 — зброя та переходи

Оглядова версія для погодження. Не фінальна інтеграційна готовність.

Базовий рендер ДО: `e549901`. Робота: `feature/avatar-core-2-weapon-transitions`, від `1e78027`. Точка відновлення: `avatar-core-2-before-weapon-pass-1e78027`. Гілка main та опублікована гра не змінювались.

## Відкрити

- [Галерея та покадрове порівняння](index.html).
- [Lab](../../avatar-lab/).
- У ZIP відкрийте `Avatar-Lab.html`, `Report.html` або `Technical-report.html` після повного розпакування. Усі три працюють без сервера й Інтернету.

| Неприродні проміжні чоловічі руки | Миттєвий непрозорий cut між затвердженими позами; старе деформування та crossfade не використовуються | Виправлено цим способом; плавний морфінг не заявляється |

Вихідні художні PNG, rig JSON, жіночі пози та математичний рушій не змінено. Нові технічні накладки й тестові props зберігаються окремо. Генератор створив атлас тестової зброї; додаткова спроба точного шаблону була відхилена інструментом і не повторювалась. Поточна версія використовує успішний атлас, а не підміняє вихідні руки.

## Дихання та переходи

4000мс та 2 CSS px залишені без зміни механізму. Кожен із 12 напрямків між idle/rifle/pistol/melee записаний кожні 16мс від 0 до 320мс: 252 кадри ДО й 252 ПІСЛЯ. Повний viewer показує кожен кадр та хеш. Усі кадри після команди збігаються з непрозорою цільовою позою. Це дискретний перехід, не анімація проміжних суглобів.

## Автоматичні перевірки

JavaScript: 95 ігрових + 20 Avatar Core = 115 успішних тестів. Python/Chromium: 42/42 успішно; остаточний журнал у test-logs/final-regression.log; кількість і результат зафіксовані в ньому. Попередній повний запуск — 42/42; фінальний запуск повторено після останньої локальної накладки. Збережений також початковий невдалий тест: повний цикл sin(2π) дає розбіжність антиаліасингу максимум 1/255 на 93 пікселях. Критерій змінено на математичне замикання координат і максимум 1 рівень растрового округлення; механізм дихання не змінено.

Перевірено byte-identical оригінальні ресурси, незмінні суглоби, похибку контактів <1e-6, усі 12 переходів, жіночі пози, збереження localStorage, відсутність JS errors/404. Chromium — реальний браузер; 320/390/768px — емуляція viewport, не фізичний телефон. Перевірка ZIP виконується після розпакування через file://; факти у offline-package-check.json.

## Відкриті питання

Не оголошується фінальна production-ready інтеграція. На великому масштабі лишається тонкий слід старого контуру під прикладом; права кисть не має окремо перемальованого пальця на спусковому гачку. У pistol на крупному плані нижній край рукоятки читається як темний фрагмент біля кисті; хват не вважається остаточно художньо узгодженим. Приклад підлаштовано як окрему частину тестового prop, його художня геометрія потребує погодження. Фізичні мобільні пристрої та інші браузерні рушії в цьому проході не перевірялись. Main, бойовий баланс, прогрес і публікація гри не змінені.
