# Пропозиція переходів — тільки для погодження

**Не реалізовано й не ввімкнено. Поточний instant cut лишається без змін.**

Найменший розумний наступний крок — окремий короткий прототип idle↔pistol з авторськими проміжними ключами рук. Не запускати знову стару деформацію опущеної руки в підняту.

1. Зберегти чинні крайні пози й ту саму систему bone/grip/bind.
2. Підготувати2 локальні проміжні композиції руки: лікоть трохи зігнутий, потім передпліччя біля корпуса. Виділяти тільки руку, не генерувати нового персонажа.
3. Показувати ключі послідовно за180–240мс: лише один непрозорий комплект рук і один непрозорий предмет у кожному кадрі. Жодних alpha crossfade.
4. Невеликий рух між близькими ключами дозволяти тільки після огляду; для великих змін — наступний готовий ключ. Відхилити прототип, якщо він читається як stop-motion або дає злам ліктя.
5. Після погодження цього одного переходу додати нижній нейтральний ключ для rifle/melee. Зміна виду предмета у спільному нижньому хваті буде дискретною, як заміна спорядження в лобі; прихованого зникнення чи плавного перетворення зброї не обіцяється.

Перевага: використовуються чинні pose-art ресурси, inverse bind та WeaponAttachmentController, без нового рига чи анімаційного рушія. Голова/таз/стопи не залучаються. Дихання зберігає власний час, його фазу не скидати.

Ціна: потрібні якісні нові проміжні малюнки. Самих обчислених IK-точок недостатньо. Без таких ресурсів чинний cut залишається кращим чесним варіантом. У поточному проході інструмент відхилив навіть локальне перемальовування хватів, тож доступність художніх ресурсів є реальним обмеженням, а не завершеною можливістю.

Критерії прототипу: покадровий огляд0–240мс, однакові ракурс і масштаб, жодного напівпрозорого подвоєння, стабільний prop/contact, відсутність стрибка довжин рук і ламаних зап’ясть. Остаточний вибір — після вашого візуального затвердження. До нього код setPose не змінюється.
