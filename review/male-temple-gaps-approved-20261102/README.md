# Погоджене закриття сірих просвітів біля скронь

Після перегляду PNG власник погодив варіант і попросив внести його в гру. Використано точні два PNG із погодженої примірки, без повторної генерації чи додаткового редагування. У малета оновлено задній шар; для кучерів додано вузький задній шар. Передні пасма, голови, тіла, мініатюри й посадка залишилися незмінними. Експериментальне тонування голови з ранньої діагностики не використовувалося.

Задні частини мають renderOrder -1 та спільний colorReference з передньою частиною, щоб закриття просвітів відповідало вибраному кольору. Шари належать зачісці й зникають після зняття/заміни та перемикання статі. Полотно 941×1672. URL ресурсів і каталогу оновлено.

integration.json містить контрольні суми точних погоджених PNG і незмінених частин. before/ зберігає попередні файли. approved-before-after.png — погоджена примірка.
