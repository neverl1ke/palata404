# Погоджений каталог зовнішності — перенесення в main

У грі: 16 жіночих голів із базовою, 10 жіночих зачісок; 16 чоловічих голів із базовою, 12 чоловічих зачісок. Вилучені F13, H03, H04 та H06 залишаються відсутніми в активному каталозі; старі вихідні PNG збережені.

Жіночі правки: усі 16 погоджених посадок із female-settings/, 32 локальні карти закриття просвітів, точні погоджені шари голів F07/F14/F17. Збережені позиції відтворюються на полотні 941×1672; донорні пікселі виправлень беруться після вибору кольору. Перевірка порівнює реальний рендер із незалежним відтворенням збережених рецептів (224 випадки). Зміни голови/кольору/статі не можуть повернути попередній асинхронний шар.

Чоловічі правки: 7 погоджених голів із власними масками шиї, 6 нових зачісок. Остаточний шостий варіант — дреди з неперервним заднім шаром за вухами/шиєю; стабільний ID збережено для старих збережень. Малет також має окремий суцільний задній шар. Збережено останню правку різкості верхівки ірокеза та підняту посадку високого вузла.

Базові тіла, старі ресурси, зброя, бойові характеристики й схема збережень не змінені. Історію експериментальної гілки Avatar Core не об’єднували: перенесено лише погоджені зміни зовнішності.

Точні погоджені композиції — sources/; контрольні суми й походження — manifest.json. Канонічні ігрові PNG — assets/wardrobe/. Налаштування — female-hair-fit-data.js; застосування — female-hair-fit.js. Регресії — tests/test_appearance_catalog.py та наявні тести Paper Doll.


Підсумок перевірок: validation.json; журнали — validation-logs.txt. Знімки справжнього інтерфейсу: female-desktop.png, female-mobile.png, male-desktop.png, male-mobile.png. Перший повний прогін виявив історичні очікування попереднього каталогу; відповідні перевірки оновлено й повторено. Для нових похідних PNG прибрано лише невидимий шум масштабування (альфа до 16/255); видимі пікселі не змінювалися. За прямою вказівкою власника №4 і базові тіла збережені без жодних змін; їхні початкові контрольні суми перевіряються окремо.
