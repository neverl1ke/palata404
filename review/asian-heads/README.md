[Новий повний звіт, до/після, чотири фони та всі зачіски](https://github.com/neverl1ke/palata404/blob/review-asian-heads-report/review/asian-heads-mask/README.md). ## Локальна інтеграція

Один пункт «Азійський тип обличчя» (`face-asian`) використовує відповідний PNG обраної статі через `genderVariants` та `fittedToGender`. Невідповідний варіант не підставляється. «Оригінальне обличчя» знімає додатковий шар. Чинне поле `appearance.face` зберігає вибір, без нової схеми чи міграції.

Рендерер аватара використовує DOM-зображення; Canvas використовується тільки для кольору волосся. Новий предмет має `renderOrder=1`: тіло `z=0` → голова `z=1` → волосся `z=9`. Порядок і параметри решти предметів не змінені. Голова також залишається під одягом і шийною допоміжною накладкою туніки.

## Знайдені проблеми

**Виправлено під час перевірки:** дробове значення `z-index=0.5` у локальній чернетці відхиляється справжнім CSS. У вже створеному основному прев’ю міг залишатися попередній рівень `11`, вище волосся. Встановлено ціле `renderOrder=1`. Новий браузерний тест перевіряє inline та computed `z-index` в обох прев’ю й після перемикання.

**Залишковий візуальний дефект, не виправлявся:** на новій чоловічій голові із зачіскою до плечей над волоссям проступає темна смужка маківки, найбільш помітна з білим волоссям. Порівняння з оригіналом у тому самому масштабі підтверджує, що на новій голові вона виразніша. Це не зміна кольору волосся та не неправильний порядок шарів: силует нової голови трохи виступає за покриття цієї зачіски. Затверджені hair placement і PNG не змінювалися. Перед публікацією потрібне окреме рішення для комбінації нової чоловічої голови та цієї зачіски, яке збереже стандартний аватар.

![Маківка: оригінальна та нова чоловіча голова з білим і синім волоссям](https://raw.githubusercontent.com/neverl1ke/palata404/review-asian-heads-report/review/asian-heads/male-crown-comparison.jpg)

На переглянутих крупних планах немає очевидних подвійних вух, другої щелепи/підборіддя, чорного фону чи яскравого ореолу. Перехід шиї збережений. Загальна художня посадка лишається на погодження власника; успішні автотести не означають відсутність наведеного візуального дефекту.

## Результати перевірок

- **67 Node-тестів** пройшли.
- **64 тести повного браузерного/ресурсного набору** пройшли; окремо пройшов **новий браузерний тест інтеграції голів**. Разом 65 перевірок Python/Chromium, 132 із Node.
- Новий тест: обидві статі, шість зачісок і відсутність волосся, комплекти «Пацієнт / Трип», viewport 1280×800 і 390×844; реальний CSS-порядок `0 → 1 → 9`; правильні PNG для статі; збереження після reload; повернення оригінального обличчя без скидання волосся чи кольору.
- Усі п’ять фінальних HEX підтверджені в браузері на обох головах. Раніше проведена піксельна перевірка кольорів зберегла альфа-канал без відмінностей; фактура, тіні й відблиски залишилися.
- Помилок JavaScript і відсутніх ресурсів у новому сценарії немає.
- Точна відповідність двох нових PNG наданому ZIP перевірена; старі аватари, PNG одягу й зачісок, усі затверджені hair placement незмінні.
