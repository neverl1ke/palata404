# Джерела та регресійні фікстури

Цей каталог більше не містить старих HTML-звітів, галерей чи масових знімків перевірок. Залишені файли потрібні для відтворення походження затвердженої графіки та перевірки незмінності ресурсів:

- оригінальні малюнки й погоджені PNG-майстри;
- реєстрації, маски та історичні джерела для порівняння;
- невеликі технічні записи, які читають чинні регресійні тести;
- контрольні кадри, безпосередньо використані тестами анімації.

Назви підкаталогів збережені, щоб не ламати посилання на джерела та тести. Поточний опис гри — [у головному README](../README.md). Видалені звіти доступні [в історії Git](https://github.com/neverl1ke/palata404/tree/b48c82d72bc26ed8359ba84d878ecb862bdf239c/review).
