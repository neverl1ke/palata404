## Перевірки та межі змін

[Прогін коду ed15917](https://github.com/neverl1ke/palata404/actions/runs/38856474770): **128 успішних перевірок** (65 Node + 63 Python). Перевірено реальне накладання в гардеробі / HUD, обидві статі й режими, перемикання, «Без зачіски», перезавантаження, незмінність ресурсів і viewport 1280×800, 390×844, 320×568 у Chromium. Фізичний телефон не використовувався. Окремо звірено тільки x −1 px першої зачіски, рівномірні 99% розміру другої та незмінність її верхньої опорної точки.

Повну різницю каталогу звірено з попереднім комітом: змінені тільки два жіночі placementByGender; усі інші поля / варіанти побайтово незмінні. PNG, чоловічі зачіски, інші жіночі зачіски, базові аватари, одяг, фони, UI, рендерер, stretchX, інвентар і збереження не змінювалися. Наявні тести не змінювалися.

Файли: `paper-doll-data.js`; лише кеш-версія каталогу в `index.html` (hairstyles-pack-02-14); документація та ці JPEG-скриншоти / звіт. Візуальних змін інтерфейсу немає.
