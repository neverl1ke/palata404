## Перевірки й межі змін

[Прогін коду e94960d](https://github.com/neverl1ke/palata404/actions/runs/38813958185): **128 успішних перевірок** (65 Node + 63 Python). Перевірено реальне накладання в гардеробі / HUD, обидві статі та режими, перемикання, «Без зачіски», перезавантаження, незмінність ресурсів і viewport 1280×800, 390×844, 320×568 у Chromium. Фізичний телефон не використовувався. Окремо звірено лише x −1 px першої зачіски, рівномірні 99% розміру другої та незмінність її верхньої опорної точки.

Різницю каталогу звірено з попереднім комітом: змінені тільки два жіночі placementByGender, усі інші поля й варіанти побайтово незмінні. Жодного PNG не змінено. Усі чоловічі зачіски, інші жіночі зачіски, базові аватари, одяг, фони, UI, рендерер, stretchX, інвентар і збереження незмінні. Наявні тести не змінювалися.

Змінені файли: `paper-doll-data.js`; лише кеш-версія каталогу в `index.html` (hairstyles-pack-02-11); документація та ці JPEG-скриншоти / звіт. Візуальних змін інтерфейсу немає.
