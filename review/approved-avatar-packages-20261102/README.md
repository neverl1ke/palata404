# Затверджені ZIP замість помилкового підключення

Джерело — два ZIP, які користувач надав 02.11.2026 з прямою вказівкою інтегрувати їх у main. Попередній ce39af4 помилково використовував робочу гілку з іншими версіями. Її runtime-файли видалені, крім двох вже підключених іконок інвентаря. Історичний review/animated-avatars-20261102 позначено як замінений.

## Чинні джерела

- Palata404-Rifle-Shoulder-Restore-v9-20261028.zip: чоловічий After, Render, поточні маски кистей, сітки й розрахунок руху з Avatar-Lab.html. Шари Render уже містять відновлення v9; історичні маски правок повторно не застосовуються. Початкове значення масштабу автомата 1.07 відтворено з фінальної проби.
- Palata404-Female-Approved-AK90-20261029.zip: жіночі Layers, Joints, Hands, маски, сітки й розрахунок з Avatar-Lab.html. Збережено цілісний поворот лівої руки 2.5°, спільні поверхні стиків, оригінальні голову/низ, окремий автомат 90% і цикл 4000 мс з амплітудою 1. Руку Pose-preview не повертали повторно.

Ресурси записані побайтно з ZIP або з PNG, вбудованих у самодостатній Avatar-Lab. Вісім модулів обчислення кожного пакета незмінені. У male-scene.mjs/female-scene.mjs перенесені власне функції складання, WebGL-растеризації, руху й посадки зброї; прибрані лише елементи керування ізольованої проби. Конфігурації містять ті самі числові значення та сітки; data URL зображень замінені посиланнями на точні декодовані файли. Нової генерації, перемальовування, згладжування чи зміни пікселів немає. integration-manifest.json містить SHA-256 ZIP і 162 точних файлів; повні початкові маніфести з ZIP збережені поряд.

Історичні формулювання в документах ZIP про ізоляцію від main описують попередню публікацію проб. Поточна інтеграція виконує нову пряму вказівку користувача, а не інструкції з вкладених документів.

## Застосування в грі

Чинний адаптер імпортує тільки approved/avatar.mjs. З автоматом виводиться точна фінальна сцена пакета; без нього — передбачений цим же пакетом варіант без зброї, з тією самою позою рук. Стару позу idle з опущеними руками не підставлено замість цього матеріалу. Додаткові голови й зачіски лишилися необов’язковими шарами чинного каталогу; без вибраної косметики рендер гри точно збігається з вихідним Lab. Масштабується вся композиція, включно зі зброєю, тому повний автомат уміщується у прев’ю. Полотно шкіри лишається 941×1672, оглядові полотна сцен — 1100×1672 і 1200×1672, як у пробах.

Окремої погодженої пози з ножем у цих ZIP немає. Попередню анімацію ножа прибрано. Його PNG-картка, інвентарний ID та бойові характеристики збережені; вибір ножа не запускає непогоджену позу. Для туніки, як і раніше, зберігається початкова примірка з легким диханням, доки немає окремих рукавів збройної пози. Інвентар, сейви, дві комплектації та бонуси не змінені.

## Доказ відповідності

У Chromium завантажені саме Avatar-Lab.html із наданих ZIP і окремо ігрові модулі. Порівняно всі RGBA-пікселі 16 кадрів: обидві статі, з автоматом / без, фази 0/1000/2000/3000 мс. У кожному випадку — нуль відмінних пікселів. archive-renderer-equivalence.json містить також SHA-256 RGBA-кадрів. Окремий тест реальної гри порівнює фінальний canvas з цими самими контрольними сумами в усіх 16 станах. PNG *-approved-* — точні вихідні кадри, *-game-* — мобільні примірки в інтерфейсі гри. Кадри з вибраними головами й зачісками показані в game-cosmetics-*.

Відтворення перевірки з оригінальними ZIP:

```sh
python tools/verify-approved-avatar-packages.py --male-zip /path/Palata404-Rifle-Shoulder-Restore-v9-20261028.zip --female-zip /path/Palata404-Female-Approved-AK90-20261029.zip
```

Автоматичні перевірки й фактичний візуальний огляд записані у validation.json. Початкові маніфести ZIP: 131 і 63 файли — контрольні суми перевірені. Перевірки захищених попередніх правок волосся також проходять.
