# Короткі кучері: очищення залишку шкіри

За вказівкою власника прибрано сіру/забарвлену смужку лоба, що була захоплена у прозорий шар `hair-m6-curly-crop`.

Виправлення виконується перед фарбуванням: тільки у виміряній ділянці нижнього контуру цього PNG видаляється альфа зв'язаних із нижньою межею залишків шкіри. Однакова очищена форма використовується для оригінального кольору та всієї палітри. Вихідні PNG, RGB кучерів, обличчя, тіла й координати посадки не перезаписані; генерація зображень не застосовувалась.

У справжньому ігровому рендерері збережені `before.png` та `after.png`: оригінальний, синій і білий кольори зліва направо. Перевірено всі 25 кольорів, усі 16 чоловічих голів у DOM, дві голови в анімованому canvas, перемикання на жіночу голову та зняття волосся. Чоловічі зачіски не додаються до жіночого каталогу.

`checks.json` містить результати: 494 очищених пікселі, жодної зміни альфа поза локальною ділянкою й жодної зміни непрозорих RGB, що залишилися. Це перевірка в Chromium, а не на фізичних телефонах.

Відтворення: `python tools/verify-curly-crop-cleanup.py`.
